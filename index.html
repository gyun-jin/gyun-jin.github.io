TROUBLESHOOTING

AWS · SERVERLESS

Spring Boot의 Lambda 실행 구조 전환

Problem
서버 프로세스를 전제로 한 Spring Boot 애플리케이션을 Lambda 요청 방식으로 바로 실행할 수 없었습니다.
Cause
Lambda에는 컨트롤러 대신 함수 핸들러가 필요하고, 실행 파일 안에 모든 의존성이 포함되어야 했습니다.
Solution
2개 Function Bean으로 API Gateway의 path parameter를 처리하고, AWS Adapter와 Maven Shade Plugin으로 전용 JAR을 구성했습니다.
Result2 Functions · 1 JAR

하나의 코드베이스에서 로컬 실행과 Lambda 실행을 지원하는 배포 구조를 완성했습니다.

LG AIMERS · MODEL STABILITY

시드별 예측 확률 편차 안정화

Problem
같은 피처로 학습해도 시드에 따라 예측값이 달라져 단일 모델의 점수가 안정적으로 재현되지 않았습니다.
Cause
일부 투구의 성공확률을 실제보다 지나치게 높거나 낮게 예측했고, 이 확률 오차가 누적돼 대회 점수가 낮아졌습니다.
Solution
서로 다른 시드 5개의 CatBoost 예측을 평균하고, Platt 보정으로 예측확률과 실제 성공 빈도의 차이를 줄였습니다.
Result1112.84 → 1126.88

2022·2023·2024 시즌 검증 평균 기준 대회 환산 점수를 14.04점 개선했습니다.

LG AIMERS · FEATURE ENGINEERING

현재 시즌 기록을 나타내는 피처 복원

Problem
통산 누적 성공률만으로는 투수의 최근 컨디션과 현재 시즌의 변화를 구분하기 어려웠습니다.
Cause
투구 수와 성공률이 시즌 경계에서 초기화되지 않고 여러 시즌에 걸쳐 계속 누적됐습니다.
Solution
현재 누적값에서 이전 시즌 종료 값을 빼 현재 시즌 기록을 복원하고, 기본 12개·상황 결합 7개 피처를 추가했습니다.
Result≈1205.6 → ≈1254.1

검증 데이터의 평균 성공률 기준 대회 환산 점수를 약 48.5점 개선했습니다.
