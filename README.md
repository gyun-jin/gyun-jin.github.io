# Park YoonJin Portfolio

데이터 분석과 AI 프로젝트를 중심으로 구성한 박윤진의 단일 페이지 포트폴리오입니다.

## 구성

- `index.html`: 소개, 프로젝트, 역량, 활동, 연락처
- `assets/css/main.css`: 반응형 레이아웃과 인터랙션 스타일
- `assets/js/main.js`: 스크롤 등장 효과와 현재 섹션 내비게이션
- `assets/images/profile.jpeg`: 프로필 이미지

## 로컬 실행

정적 파일이므로 `index.html`을 직접 열거나 아래 명령으로 확인할 수 있습니다.

```bash
python3 -m http.server 8765
```

브라우저에서 `http://localhost:8765`로 접속합니다.
